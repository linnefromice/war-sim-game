# Self-review

Codex単独で差分全体・既存呼び出し元・回帰検査・ブラウザ画像を確認。

## 修正した指摘

- **面の取り違え**: reducer・地形移動BFS・ダメージ計算・手番・盤面描画・キーボード境界・リプレイがtutorial固定だった。選択面を明示して統一。tutorial定義自体は変更していない。
- **ホットシート阻害**: Player 2のキーボード/確定を無条件に止め、自動AIを起動していた。既存CPUセーブのdifficultyがある場合だけ既存AIを有効にする。新規セッションにdifficultyを渡さない。
- **不正操作**: キーボード経由で占有マス・射程外・再行動を実行できた。reducerで拒否し、拒否時に履歴もアニメーションも作らない。未知ID・不正武器・不足EN・味方攻撃も拒否。
- **取消の巻き戻り**: 後の手番でもspawnへ戻る実装だった。直前の移動元へ戻し、移動元が埋まった場合は拒否する。統計側もUNDO_MOVEを反映して強襲補正を解除。
- **攻撃対象表示**: 味方への攻撃を防ぐ際、味方マスを空表示にしていた。味方の表示を維持する回帰検査を追加。
- **入力フォーカス**: グローバルのTab/Enterがボタンと競合し、戦場から抜けられなかった。戦場にフォーカスがある時だけ戦場キーを処理し、ボタンのネイティブ操作とShift+Tabを維持。9本のブラウザ検査内にキーボード完走を含める。
- **操作の重なり**: 絶対配置の行動メニューを盤面下へ移し、狭い画面では盤面だけ横スクロール。320/768/1366px × 4面で行動パネルが盤面を覆わずページ横溢れがないことを検査。
- **結果の狭幅表示**: 既存統計パネルが390px画面でx=-70/幅530となり閉じる操作もなかった。幅と表の列幅を画面内に制限し、閉じるボタンを追加。リプレイのpadding込み幅も修正。ブラウザで統計/リプレイの矩形が画面内に収まることと実際に閉じられることを検査。
- **保存互換/破損**: version 1はtutorialと元の難易度を維持。version 2は面IDを保持。破損した座標/spec/HP/履歴/勝者等をロード前に拒否。保存不能も画面へ通知。
- **リセット**: AppからStageをkey付きで再生成。HP/EN、座標・向き、移動/攻撃済み、手番、勝者、履歴、カーソル、選択UI、保留アニメーションが持ち越されないことを回帰検査と実UI保存の読み取りで確認。
